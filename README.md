# HyperMount

[English](README.en.md) | 简体中文

一个 **SystemUI 界面替换与自动救砖** 的控制端 App 小米 HyperOS 风格界面

![Android](https://img.shields.io/badge/Android-15%2B%20(API%2035)-3DDC84?logo=android&logoColor=white)
![Root](https://img.shields.io/badge/Root-Required-D32F2F)
![License](https://img.shields.io/badge/License-AGPL--3.0-blue)

<br>

围绕「**备好救砖界面 → 换入待测界面 → 崩了自动换回 → 继续正常使用**」这条主链路设计：放胆把会崩的界面换进去试 出事自动换回可用的那一版 不再怕 SystemUI 黑屏卡死

同一套「装上 → 抓崩溃 → 回滚」也搬进了组件页 任意 apk 都能这么测

## ✨ 功能

### 系统界面（底栏第一页）

- **状态卡**：守护中 / 空闲、PID、累计救砖次数、运行输出实时回显
- **救砖界面**：选一个确认可用的 SystemUI 留作后路 出事时换回它
- **待测界面**：选要实测的那一版界面 换进去观察
  - 点选文件直接拉起 MT 管理器（正版优先 没装再走共存版）
  - 两个版本都没装时会提示找不到 MT 管理器 不会退回别的选择器
  - 下载器留下的 `apk.1` 后缀会自动还原成 `apk`
  - 复制完成先校验包名 不是 `com.android.systemui` 的一律拒收
- **界面快照**：记下当前安装的那份界面 可重命名 / 设为救砖 / 导出 / 撤销
  - 撤销就是直接删掉刚记的那条 不再二次确认
- **开始 / 停止**：一键接管 随时可以喊停
  - 音量键还没校验过会先拦一道 救砖全靠它 按不动等于白测
- **设备**：系统版本与机型

### 配置（界面页右上角齿轮）

- **运行模式**：完全禁用 / 仅日志 / 日志 + 救砖
- **开机记录日志**：开机就把日志写起来
- **开机启动全局救砖**：开机稳定后自动开始守护 不限制时长
- **全局常驻救砖**：不开着 App 也一直守着
  - 时长 1 小时到 6 小时连续可拖 2 / 4 / 6 小时会吸附 最右一截是「无限制」
  - 判定条件自己定：多少秒内 SystemUI 重启多少次就进入守护（5 到 60 秒 / 2 到 5 次）
  - 守护跑起来带一条常驻通知 切后台、锁屏都不会被系统清掉
- **救砖逻辑**
  - **音量键校验**：独立页逐个实测 设备声明了 ≠ 真能按出事件
  - **增强救砖**：崩溃条数到阈值就自动换回 不用等音量键（阈值 1 到 10 条可调）
  - **屏蔽系统救援**：把系统的崩溃重启上限拉高 免得它抢在前面把 SystemUI 收走
    - 开增强救砖时强制打开且不可关闭
    - 日志 + 救砖模式下上限设为 **30** 比系统默认的 12 宽 音量键才来得及按

### 组件（底栏第二页）

- 不依赖模块守护 自己跑一套「装上 → 抓崩溃 → 回滚」 测别的 App 崩不崩也能用
- **状态卡**：测试中 / 空闲、上次结果与时间、自动回滚开没开、累计回滚次数、运行输出实时回显
- **崩溃自动恢复**：崩了自动换回 关掉也能只抓日志
- **救砖组件**：能从组件快照里挑一份 不指定就直接回滚到系统预装版
- **待测组件**：要装进去试的那个 apk
- **组件快照**：记录 / 重命名 / 设为救砖 / 导出 / 撤销
- **回滚组件**：不经过崩溃检测 点了就退回预装版 界面会重启一次
- **开始测试**：装上待测组件 按设定时长只抓 crash 缓冲区
- **配置**（右上角齿轮）：抓取时长、日志大小判定
  - 抓哪个包固定在 SystemUI 进程 组件都跑在里面 换个包名只会抓不到东西
- **不校验包名** 只拦「待测和救砖是同一个文件」
- 与系统界面页完全独立 两份 apk 各存各的 一边跑测试不影响另一边
- 所有滑动条都支持点标题区域直接敲数值

### 检查更新

- 启动时后台查一次 有新版就在版本号右侧亮出更新胶囊 点一下直达下载
- 设置页「关于」卡里的「检查更新」可手动复查 期间整行变灰不会重复点
- 同一张卡里的「自动检查更新」开关可以关掉启动时那次检查
- **更新来源**可选正式版或内测版 想尝鲜切到内测版 不需要了切回正式版即可
- 查到的结果会记住 断网或者重启 App 都不会把更新提示弄丢

### 界面与主题（设置右上角）

- Miuix 风格 支持深色模式 顶栏是可收缩的大标题
- **底栏三页**：系统界面 / 组件 / 设置 只能通过底栏切换 左右滑动不再翻页 避免误触
- **主题模式**：跟随系统 / 浅色 / 深色
- **莫奈取色**：跟着壁纸取主色
- **种子色**：自己指定主色 带调色风格与色彩规范
- **iOS 底栏**：换一套悬浮玻璃胶囊底栏
- **底栏折射**：只对 iOS 底栏有意义 关掉后退化成磨砂胶囊 不做折射
- **模糊强度**：玻璃控件的模糊程度 0 到 200% 可调 拖动即时生效 带一键重置
- **预测性返回手势**：根据手势预览上一级 关闭后拖动时页面不动 松手才返回 圆角按系统圆角裁切

### 设置

- **语言**：跟随系统 / 简体中文 / English 模块端的安装提示与操作台文案也跟着切
- **日志目录**：点按走系统目录选择器 长按手动填路径
  - 选择器解不出真实路径时会提示改手填 不会静默失败
- **缓存大小**：上限 100 MB 到 1 GB 无级可拖 最右是无限制 也能勾选后一次删干净
- **MCP 服务**：给 AI 客户端接进来 默认关闭
  - 开关、局域网访问、访问密码、连接地址、访问令牌、自定义端口与令牌
- **关于卡**：关于 / 检查更新 / 自动检查更新 / 更新来源
- **开发者选项**：单独一张卡 放在整页最下方 正式包也保留
  - 应用日志等级、应用日志内容（等级为「关闭」时这一行自动收起）
  - 进入 OOBE：不用清数据 直接重看一遍引导
- 冷启动会回到上次停留的那一页

### 引导（OOBE）

- 六步：欢迎 / 权限 / 协议 / 基础设置 / 音量键 / 完毕
- 权限页逐项给状态：通知 / 存储 / ROOT / 救砖模块 / 自启动 缺哪项点哪项
  - 自启动与存储只能去系统设置里开 回来会自动对一次状态
- 基础设置页直接改运行模式 / 日志目录 / 语言
- 音量键当场实测 按不出来就不让往下走
- 只有引导内容改过才重新走一遍 普通发版不会平白打扰老用户

### 关于

- 入口在设置页「关于」卡 点进去是二级页
- 开发者与代码协助、应用版本、模块版本
- **捐赠**：跟在模块版本下面
- **更新卡**：App 有新版时卡内直接下载并安装 模块有新版时只下载 zip
- 官网 / GitHub 仓库 / AGPL v3.0 / 第三方许可证
- **移植参考**：玻璃与光晕的参考项目单列一页 不算第三方依赖

## 🧩 源码与构建

本仓库就是发布包的**完整来源**：没有闭源组件、没有加固壳、没有运行时下发的代码。发布包里出现的每一个二进制，都能在这里找到对应源码。

| 目录 | 内容 |
| --- | --- |
| `app/` | Android 客户端（Kotlin / Compose） |
| `module/main/` | 模块本体（`customize.sh` / `service.sh` / `action.sh`、脚本与默认配置） |
| `module/main/language/` | 模块端中英文文案（安装提示、操作台、`module.prop` 描述） |
| `module/src/` | 模块守护与命令行的 C 源码（`actiond.c` / `watchd.c` / `ctl.c`） |
| `module/build-bin.sh` | 交叉编译 `module/src`，产出 `module/main/bin/` 下的 arm64 可执行文件 |

`module/main/bin/` 里的二进制一并入库，是为了让没有 NDK 的环境也能打出完整模块包（守护没有 shell 兜底，缺它就是缺功能）。它们全部由 `module/src/` 里的同名 `.c` 编译而来，可以自行重编后与发布包内的文件比对。

> 发布包内只放编译产物、不放源码；源码以本仓库为准。
